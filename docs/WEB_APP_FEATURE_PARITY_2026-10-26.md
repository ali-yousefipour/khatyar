# تکمیل صفحه‌های وب‌اپ — ۲۰۲۶/۱۰/۲۶

## مسیر فعال و دامنه

نوع تغییر: رفتار و رابط وب‌اپ، همراه با تکمیل قرارداد خواندن اقلام تحویلی. `/app` طبق rewrite موجود به `php/app/app-shell.php` می‌رود و منبع `app.html` را با اسکریپت‌های deferred می‌فرستد. فایل‌های untracked قدیمی `web-app.js/css` منبع این تغییر نیستند.

لایهٔ `android-web-parity.js` دیگر بارگذاری نمی‌شود؛ این لایه endpointهای حدسی و چند دکمه با پیام موفقیت بدون ذخیره‌سازی داشت. منو از `android-navigation.js` و همان دسترسی‌های Android خوانده می‌شود. نام‌های `PastNotices` و `ReportDetail` به rendererهای موجود با حروف صحیح متصل شدند.

ثبت درخواست جایگزین تنها برای استحقاقی روزانه انجام می‌شود. بازه ساعتی باید شروع کوچک‌تر از پایان داشته باشد. تردد دستی شبانه طبق قرارداد موجود سرور حذف نشده است. خطای مانده مرخصی جلوی نمایش سابقه و فرم درخواست را نمی‌گیرد و صریح نمایش داده می‌شود.

`/my/sms-quota-v2` در منبع PHP موجود نیست؛ وب از مسیر واقعی `/my/sms-quota` استفاده می‌کند. اقلام تحویلی قبلاً پنج GET فراخوانی‌شده توسط Android را نداشت؛ این قرارداد اکنون برای هر دو مصرف‌کننده موجود است. endpointهای نوشتن اقلام و محاسبه موجودی تغییر نکرده‌اند. schema تازه‌ای اضافه نشده است.

## بررسی و اعتبارسنجی محلی

- `node php/tests/web_features_test.cjs`: موفق؛ inventory تمام آیتم‌های داشبورد/منو/تنظیمات (وسیله پرسنلی با ابزار موجود)، loaderها، خطای دسترسی، صفر checkbox، date شمسی و اسفند کبیسه، escape، دانلود هم‌مبدأ، جلوگیری از ارسال تکراری و نشست قدیمی؛ اجرای callbackهای واقعی wizard مأموریت و رد ساعت معکوس؛ رد JSON نامعتبر.
- `php php/tests/inventory_read_contract_test.php`: موفق؛ اجرای closureهای واقعی خواندن با query recorder، محدودیت user، صفر موجودی، حداقل داده گیرنده و binding فیلتر admin. این آزمون جای اجرای MySQL واقعی نیست.
- `node php/tests/android_web_navigation_test.cjs`، `node php/tests/android_web_screens_test.cjs`، `node php/tests/login_policy_ui_test.cjs`: موفق.
- `php php/tests/zone_context_test.php` و `php php/tests/request_substitute_scope_test.php`: موفق.
- `php -l php/lib/routes.php` و `php -l php/app/app-shell.php` و syntax شش ماژول JS: موفق.
- build رسمی از پوشه php با `bash ./tools/build_panel_bundle.sh` و `node --check app/assets/panel.bundle.js`: موفق؛ bundle نسبت به HEAD diff معنایی ندارد و وارد commit نمی‌شود.
- بازبینی diff و `git diff --check`: موفق؛ فایل‌های خصوصی، SQL ورودی، APK، وابستگی‌ها و تغییرات محلی قبلی وارد commit نمی‌شوند.

## محدودیت‌ها و موارد تأییدنشده

- این سند برابری کامل تمام جزئیات Android را ادعا نمی‌کند. دانلود تصویر A5 حقوق شرکت، editor برش مدارک، امکانات مدیریتی کامل سرویس مدارس و نقشه آفلاین در این مرحله هم‌ارز Android نشده‌اند. فایل‌های فیش پیوستی قابل دانلودند و جزئیات حقوق شرکت نمایش داده می‌شود.
- API `/crash-reports` که Android صدا می‌زند در PHP جاری وجود ندارد؛ صفحه وب صریحاً ثبت محلی و دانلود دارد و ارسال سروری را موفق اعلام نمی‌کند.
- قفل مرورگر محلی است و جای امنیت حساب یا قفل سیستم را نمی‌گیرد؛ با حذف داده مرورگر حذف می‌شود. اثر انگشت، PTT سخت‌افزاری و سرویس پس‌زمینه Android معادل کامل مرورگری ندارند.
- تعامل گرافیکی تولید، عکس/GPS/میکروفن روی گوشی و نوشتن عملیاتی در DB زنده تأیید نشده‌اند. ابزار Computer Use در بررسی قبل به علت ناتوانی تشخیص مطمئن URL متوقف شد؛ از آن برای دور زدن محدودیت یا ارسال فرم واقعی استفاده نشده است.
- وضعیت commit، workflow و تطبیق HTTP در گزارش تحویل جداگانه ثبت می‌شود؛ موفقیت محلی به‌تنهایی اثبات انتشار نیست.
