# قالب ثابت اطلاعیه تغییرات خطیار برای کانال نرم‌افزار

این فایل قالب مرجع پیام انتشار نسخه‌های بعدی است. متن نمونهٔ نسخهٔ ۱.۵.۱۶ در [نمونه اطلاعیه](CHANNEL_RELEASE_EXAMPLE_1.5.16_FA.md) نگهداری می‌شود.

## شیوه استفاده

1. شماره نسخه و تاریخ ماه/سال شمسی را فقط از نسخهٔ واقعاً منتشرشده بگیرید؛ شماره نسخهٔ سایت و اندروید ممکن است متفاوت باشند.
2. تغییرات تأییدشدهٔ همان انتشار را از `CHANGELOG_CURRENT.md` و تغییرات مخزن استخراج و در گروه‌های موضوعی شماره‌دار قرار دهید. تعداد و عنوان بخش‌ها ثابت نیست.
3. هر بخش با یک ایموجی، شماره فارسی و عنوان کوتاه شروع شود؛ زیر آن چند مورد روشن و قابل‌فهم برای کاربران با `-` درج شود.
4. از اصطلاحات فنی غیرضروری و ادعاهای تأییدنشده مانند «رفع کامل» یا «منتشر شد» قبل از ساخت و ارائه نسخه خودداری کنید.
5. دو خط وضعیت نسخه‌ها، شعار پایانی و تشکر از همکاران حفظ شوند. اگر APK جدید هنوز منتشر نشده است، وضعیت آن صریح نوشته شود.
6. متن آماده را برای کانال کپی کنید؛ ثبت در مخزن به‌معنای ارسال خودکار پیام به کانال نیست.
