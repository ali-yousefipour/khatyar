# پیاده‌سازی گزارش تردد

فایل `attendance-report-columns-v2.js` لایه نمایش گزارش را به جدول استاندارد تبدیل می‌کند و ستون‌های گزارش، تنظیم ستون‌ها و طبقه‌بندی روز عادی/جمعه/تعطیل را اعمال می‌کند.

در نسخه فعلی، دادهٔ اصلی گزارش از `__khatyarAttendancePayload` خوانده می‌شود. برای روز عادی، موظفی از دادهٔ شیفت حفظ می‌شود. برای جمعه و تعطیل، موظفی و کسری صفر و زمان حضور به ترتیب در جمعه‌کاری یا تعطیل‌کاری/اضافه‌کاری قرار می‌گیرد.

برای خروجی Excel، همان payload اصلاح‌شده مصرف می‌شود. دکمه تکراری با عنوان «خروجی XLSX گزارش تردد» توسط `attendance-xlsx-duplicate-button-fix.js` حذف می‌شود و خروجی اصلی حفظ می‌گردد.
