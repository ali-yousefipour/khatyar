# ناوبری مشترک وب‌اپ و Android

مسیر فعال `/app` از `php/app/app-shell.php` و `app.html` استفاده می‌کند. ظاهر و ناوبری وب از منبع جاری DashboardScreen، DrawerMenuScreen و SettingsScreen اندروید استخراج می‌شود؛ نسخهٔ محصول تغییر نمی‌کند.

پس از تغییر منوی Android اجرا کنید:

```sh
node php/tools/build_android_web_navigation.cjs
node php/tests/android_web_navigation_test.cjs
```

`android-navigation.js` خروجی تولیدی است. نام، ترتیب، دسته، رنگ و آیکون کارت‌ها، هفت مسیر کشوی اصلی، تنظیمات و متن حریم خصوصی از منبع Android می‌آیند. نگاشت کوچک آیکون‌ها و فونت MaterialCommunityIcons متعلق به وابستگی فعلی Expo 15.0.2 هستند؛ مجوز کنار فونت نگهداری می‌شود.

`android-app.css` چیدمان واکنش‌گرا و `android-app-ui.js` تنظیمات، اطلاعات برنامه و نمایش صف موجود را فراهم می‌کنند. ترتیب کارت‌ها به تفکیک حساب در مرورگر ذخیره می‌شود. جستجو با دسته‌بندی اشتراک گرفته و مجوزهای موجود، قابلیت‌های سازمان، دسترسی مدرسه و مجوز پیامک حفظ می‌شوند. درج خودکار مسیرهای جزئیات در کشو توسط دو لایهٔ قدیمی حذف شده است؛ مسیرهای داخلی حذف نشده‌اند.

این تغییر، تطبیق ظاهر و ناوبری است؛ تکمیل تمام قابلیت‌های Native در مرورگر نیست. مسیرهایی که قبلاً در وب placeholder یا نیازمند امکانات Android بوده‌اند همچنان محدودیت قبلی را دارند. API، ورود، داده‌های عملیاتی و محاسبات تغییر نکرده‌اند. تست VM جای آزمون روی گوشی واقعی و کنترل تمام گردش‌های عملیاتی نیست.

Service worker پوسته و دارایی‌های جدید را در cache جدید نگه می‌دارد؛ درخواست‌های API همچنان خارج از cache هستند. انتشار موفق فایل‌ها و آزمون HTTP از آزمون تعاملی مرورگر مستقل‌اند.

دکمهٔ ارسال مجدد همان تابع صف موجود را صدا می‌زند. این تابع برای جلوگیری از ارسال هم‌زمان یک batch توسط اتصال مجدد و کلیک کاربر، یک اجرای مشترک دارد؛ تست با پاسخ معلق، تعداد واقعی POST را بررسی می‌کند.

## زیرصفحه‌ها — ۲۰۲۶/۱۰/۲۵

منبع Android برای جستجو `SearchScreen.js`، مشخصات تاکسیران `DriverScreen.js`، خودرو و سوابق `ListScreens.js` و بی‌سیم `RadioScreen.js` است. مسیر اجرای وب همچنان همان توابع `screens` و handlerهای `app.html` است؛ renderer موازی، endpoint یا schema تازه ساخته نشده است.

| صفحه | داده و مسیر موجود | تغییر |
| --- | --- | --- |
| جستجوی تاکسی و تاکسیران | `GET /api/search?national_id=...` یا `plate=...`، تابع ثبت‌شده در `php/lib/routes.php`؛ جداول drivers، vehicles، vehicle_drivers و lines | تب‌های اندروید، فرم کد ملی، پلاک زرد، اعتبارسنجی رقم فارسی/عربی، قفل کلیک تکراری و رد نتیجهٔ دیررس |
| نتیجه خودرو | پاسخ vehicle و drivers همان جستجو | صفحهٔ مشخصات تاکسی، کارت رانندگان و شیفت/کد در خط؛ رعایت access_blocked و block_reason سرور |
| مشخصات تاکسیران | driver، vehicle، warnings و temp_lines پاسخ جستجو | مشخصات، پلاک، اعتبارها، خطوط موقت، حفظ صفر و ۸ اقدام اصلی |
| سوابق چک‌لیست | `GET /api/checklists/{driverId}`؛ checklist_submissions و checklist_items | موارد خوانا و تصویر خصوصی با دریافت احراز‌شده، بدون ارسال token به دامنهٔ دیگر |
| سوابق پیامک | `GET /api/drivers/{id}/sms`؛ sms_log و users | متن، ثبت‌کننده، تاریخ و وضعیت |

| سایر صفحات موجود | handler و API قبلی بدون تغییر | کارت، فرم، تب، جدول، دکمه، پیام خطا و فاصله‌های مشترک واکنش‌گرا |

بی‌سیم از `initialize=1` قرارداد موجود برای مرز شنود زنده استفاده می‌کند. پاسخ، پخش و ضبط با نسل نشست کنترل می‌شوند؛ تغییر کانال، خروج و مخفی‌شدن صفحه صدای قبلی را متوقف می‌کند. پیام‌های اخیر خودکار پخش نمی‌شوند. رد autoplay دکمهٔ تلاش مجدد دارد. رهاکردن زودهنگام، لغو مجوز میکروفن و ضبط زیر حداقل، پیام ارسال نمی‌کند. channel_id ضبط و آزادسازی ثابت می‌ماند. MIME فایل ارسالی از پارامتر codec جدا می‌شود تا با قرارداد فعلی PHP سازگار باشد؛ bitrate و حجم با سقف موجود هماهنگ‌اند و پیش از انقضای lease حاشیهٔ زمانی در نظر گرفته شده است.

آزمون مکمل:

```sh
node php/tests/android_web_screens_test.cjs
php php/tests/radio_live_test.php
node php/tests/radio_admin_live_test.cjs
node mobile/scripts/test-radio-live.cjs
```

این آزمون‌ها داده و دستگاه آزمایشی دارند و ارسال واقعی صوت، کیفیت صدا یا ظاهر روی گوشی را تأیید نمی‌کنند. امکان دکمهٔ فیزیکی PTT مربوط به Android است و در وب به‌عنوان قابلیت فعال نمایش داده نمی‌شود. گردش‌های اختصاصی Android که قبلاً در وب پیاده نشده‌اند، صرف تغییر CSS تکمیل نشده‌اند.
