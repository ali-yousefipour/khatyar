# نسخه 1.3.68 — یکپارچه‌سازی ثبت موقعیت ایستگاه با خطوط تاکسیرانی

تاریخ: 2026-08-26

## نتیجه تغییر

قابلیت «ثبت موقعیت و تصویر خطوط» دیگر یک ابزار عمومی در صفحه ورود پنل نیست. دسترسی آن پس از ورود و بر اساس Permissionهای موجود در API ثبت موقعیت کنترل می‌شود.

## پنل ادمین

- دکمه‌های مستقل ثبت موقعیت و مجوز سمت‌ها از `php/app/panel.html` حذف شدند.
- `php/app/assets/line-location-admin-bridge.js` به shell پنل اضافه شد.
- در بخش خطوط تاکسیرانی، برای رکورد هر خط امکان مشاهده آخرین موقعیت، دقت GPS، تصاویر محل و تابلو و تاریخچه موقعیت‌ها فراهم شده است.
- داده‌ها از `line-location-api.php` خوانده می‌شوند و به همان `line_id` متصل هستند؛ رکورد موازی برای خط ایجاد نمی‌شود.

## Web App

- مسیر `/app` همچنان از `php/app/app.html` استفاده می‌کند.
- لایه parity موجود مسیر ثبت موقعیت را در داشبورد نگه می‌دارد.
- `Permissions-Policy` به `camera=(self)` تغییر داده شد تا Camera API در مبدأ سایت مسدود نباشد.
- نسخه 1.3.68 با badge قابل مشاهده است.

## Android

- `LineLocationScreen` و route `LineLocation` از قبل در پروژه وجود داشتند و حفظ شدند.
- ثبت تصویر با Camera UI انجام می‌شود و انتخاب Gallery در این Screen ارائه نشده است.
- GPS با `Accuracy.Highest` دریافت و Backend دقت حداکثر 20 متر را برای ثبت ایستگاه الزام می‌کند.
- نسخه Android به 1.3.68 و versionCode به 10368 افزایش یافت.

## Permission

سه مجوز اصلی همچنان مرجع هستند:

- `can_capture`: ثبت/بروزرسانی موقعیت و تصاویر
- `can_view`: مشاهده موقعیت و تاریخچه
- `can_manage`: مدیریت Permission سمت‌ها

## موارد نیازمند تست Production

1. تست ورود با نقش‌های مختلف و اطمینان از عدم نمایش قابلیت پیش از Login.
2. تست ثبت یک ایستگاه واقعی با GPS دقیق و دو تصویر.
3. بررسی نمایش همان اطلاعات در رکورد خط در پنل.
4. تست تاریخچه چند ثبت برای یک خط.
5. تست Camera/Geolocation روی Chrome Android.
6. تست APK نسخه 1.3.68 روی Android 9 و Android 10.
7. پس از deploy، اطمینان از همسان بودن نسخه API با 1.3.68.
