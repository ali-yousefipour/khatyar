# قواعد برند و سطح داشبورد خطیار

این سند قواعد همین سطح اندروید را از تم فعلی پروژه تثبیت می‌کند.

- هدف صفحه دسترسی سریع نیروی عملیاتی به ابزارهای مجاز و مرور آمار شخصی است.
- نام، سمت، منطقه، دسترسی‌ها، آمار و ترتیب ذخیره‌شده از منابع فعلی برنامه خوانده می‌شوند.
- رنگ اصلی سبز #086b56، متن #142033، متن ثانویه #314159 و زمینه #f6f8fc است.
- زرد تاکسی #ffc928 برای تاکید محدود و کمتر از ده درصد سطح استفاده می‌شود.
- فونت Vazirmatn با نقش‌های عنوان ۲۳، عدد ۲۶، ابزار ۱۴ و توضیح ۱۲ تا ۱۳ است.
- هدف لمس حداقل ۴۴ واحد است. ابزارها حداقل ۹۲ واحد ارتفاع دارند و با متن بلند رشد می‌کنند.
- در عرض کمتر از ۳۸۰ یا بزرگ‌نمایی فونت بالای ۱٫۳ ابزارها تک‌ستونه‌اند. محتوای عریض حداکثر ۹۶۰ واحد است.
- آیکن‌ها از MaterialCommunityIcons هستند.
- DashboardTool و DashboardMetric اجزای مشترک همین سطح‌اند و رنگ‌ها از theme.js می‌آیند.
- وضعیت بارگذاری دسترسی، خطا، نتیجهٔ خالی، جست‌وجو و بازیابی باید قابل تشخیص باشد.
- تاریخ شمسی و اعداد فارسی مطابق توابع فعلی برنامه نمایش داده می‌شوند.
- مرجع تصویری صرفاً جهت چیدمان است. داده و عنوان‌های نمایشی آن مجوز تغییر قرارداد محصول نیستند.
