# تقویم شیفت نیروهای جایگزین — وضعیت اجرایی ۲۰۲۶/۱۱/۲۷

این قابلیت هنوز تأیید پذیرش کامل عملیاتی ندارد. این سند وضعیت فعلی است، نه مجوز تغییر داده تولیدی.

## مسیر فعال

`ShiftManager → SubstituteCalendar → /api/admin/substitute-calendar → LeaveSubstituteCoverage::status`؛ فهرست نیروها از `/api/admin/substitute-calendar/users` با کنترل is_admin سمت سرور دریافت می‌شود. Android از همان status در `/api/my/shift-cover-status` استفاده می‌کند. منبع پنل `php/tools/panel_source.jsx` و خروجی آن `php/app/assets/panel.bundle.js` است.

## پیاده‌سازی

- تقویم جلالی شنبه‌محور، انتخاب/جستجوی نیرو، ماه/سال، ماه قبل/بعد/جاری، به‌روزرسانی و تازه‌سازی دقیقه‌ای؛ واکنش‌گرا و دارای خطا، وضعیت خالی و جزئیات با dialog بومی.
- تخصیص قطعی، رزرو موقت و سوابق لغو/رد/آزادسازی جدا هستند؛ رزرو موقت حضور یا کارکرد ایجاد نمی‌کند.
- همه بخش‌های شیفت اصلی همان تاریخ با ShiftCalc خوانده می‌شوند؛ نام نیروی اصلی، رزروکننده احراز هویت‌شده و زمان رزرو نمایش داده می‌شوند.
- تخصیص‌ها، روزهای شیفت و اطلاعات رزرو به‌صورت batch خوانده می‌شوند؛ تغییر جایگزین/تاریخ از منبع requests و audit منعکس می‌شود.
- هشدار تداخل میان رزروها با بازه نیمه‌باز، چند بخش و عبور از مرز ماه؛ هشدار نمایشی ادعای پوشش کامل سایر ضوابط کاری ندارد.
- کنترل مشترک رزرو/تأیید/ویرایش، قفل advisory، تداخل با شیفت شخص و مرخصی ساعتی، و محافظ ماه نهایی‌شده.
- شیفت‌های ثابت با سیاست محاسباتی یکسان به‌صورت composite و با حفظ بخش‌ها، موظفی صریح و شیفت اصلی خود شخص محاسبه می‌شوند. سیاست‌های متفاوت و بازه‌های نامشخص، خودکار یا شناور محافظه‌کارانه رد می‌شوند؛ پشتیبانی کامل آن‌ها ادعا نشده است.
- Excel براساس فیلتر و چاپ/ذخیره PDF از مسیر چاپ مرورگر، نه PDF مستقل سمت سرور.
- Android همه کارت‌های تخصیص و رزرو موقت را نشان می‌دهد؛ build APK و آزمایش گوشی انجام نشده‌اند.
