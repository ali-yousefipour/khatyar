# زمان‌بندی کرون‌های خطیار

مسیر تأییدشدهٔ هاست در ۲۰۲۶/۱۰/۲۴: `/home/h301194/app`، PHP پیشنهادی cPanel: `/usr/local/bin/php`. فرمان پایه `/usr/local/bin/php -q /home/h301194/app/FILE.php` است؛ بین PHP و مسیر فایل فاصله لازم است. PHP و wget دو روش مستقل‌اند و نباید پشت سر هم به PHP داده شوند.

- `cron_auto_exit.php`: هر ۱۵ دقیقه.
- `cron_sms_expiry.php`، `cron_push_expiry.php`، `cron_birthday.php`، `cron_cleanup.php`: هر کدام روزی یک بار با زمان‌های مستقل.
- `cron_daily.php`: صرفاً جایگزین چهار کار قبلی؛ همراه آن‌ها اجرا نشود.
- `cron_mission_scoring.php`: فقط پایان روز کاری؛ اجرای جامعِ ساعتی باعث امتیازدهی زودهنگام می‌شود.
- `radio-cleanup.php`: روزی یک بار، بر اساس مدت نگهداری تنظیم‌شده.
- `cron_bale.php`: هر پنج دقیقه؛ پس از رفع خطای comment در نسخهٔ فعلی.
- `cron_background.php presence-alert`: هر دقیقه؛ فقط سیاست حضور فعال را اجرا می‌کند.
- `cron_background.php delivery-queue`: هر دقیقه، حداکثر ۵۰ پیام در هر اجرا از همان handler موجود.
- `cron_background.php system-health`: هر پنج دقیقه، همان handler پایش موجود.

ورودی background فقط CLI است و فقط سه handler مشخص را از routes.php می‌پذیرد. کلید موجود cron_key را داخل سرور می‌خواند و به قرارداد احراز هویت همان handler می‌دهد؛ کلید در command، URL، خروجی یا لاگ ثبت نمی‌شود. کلید خالی رد می‌شود؛ کلید تازه ساخته نمی‌شود. قفل MySQL برای هر task از اجرای هم‌زمان جلوگیری می‌کند. نتیجه در cron_run_log ثبت و در پایش کرون‌های پنل نمایش داده می‌شود. گزینهٔ `--check` فقط اتصال bootstrap و ثبت handlerها را بررسی می‌کند و task را اجرا نمی‌کند.

ساعت crontab الزاماً ساعت تهران نیست. پیش از تبدیل ساعت‌های روزانه، منطقهٔ زمانی زمان‌بند هاست را با اجرای مشاهده‌شده مقایسه کنید؛ تنظیم timezone در PHP به‌تنهایی منطقهٔ زمانی cron daemon را تغییر نمی‌دهد. فعال بودن ردیف cPanel با اجرای موفق یا ارسال موفق پیام یکی نیست. تا اجرای بعدی، کارهای روزانه تأیید عملیاتی محسوب نمی‌شوند.

آزمون `php tests/cron_background_test.php`، با fixture و فرآیندهای مستقل، قرارداد سه handler، منع task دلخواه، کلید خالی، قفل هم‌زمانی، ثبت خطا و عدم افشای کلید را بررسی می‌کند؛ هیچ پیام یا عملیات واقعی تولید انجام نمی‌دهد. syntax همهٔ cronها و radio-cleanup پیش از انتشار در CI کنترل می‌شود.
