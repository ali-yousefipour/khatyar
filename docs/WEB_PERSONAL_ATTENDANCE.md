# ثبت حضور من در وب

مسیر فعال: منوی Android مشترک `CheckIn` → alias `checkin` → `web-attendance.js` که پس از ابزار مشترک در `app-shell.php` بارگذاری می‌شود. handler قدیمی GPS و رندر تب قدیمی از app.html حذف شدند؛ رندر جدید کامل است و after-render موازی ندارد.

نوع تغییر: ظاهر و رفتار. PHP، MySQL، schema، محاسبات حقوق/کارکرد، اعتبارسنجی محدوده و مجوزها تغییر نکردند.

## قرارداد واقعی

- GET `/my/checkin-config`: خطوط مجاز، روش‌های فعال، geofence و حضور باز. از GET cache قدیمی استفاده نمی‌شود.
- GET `/my/work-timer`: مجموع حضور امروز، موظفی، مانده، اضافه‌کار و مازاد، طبق پاسخ سرور؛ با صفر جایگزین‌کردن دادهٔ غایب، کارکرد ساختگی نمایش داده نمی‌شود.
- POST `/my/checkin` یا `/my/checkout`: مختصات واقعی، accuracy، method=gps، client_time و client_uuid. انتخاب خط خودکار و تأیید نهایی بر عهده سرور است. مرورگر به‌جای Wi-Fi/GSM شناسه یا مدرک ساختگی نمی‌فرستد.
- GET `/my/daily-performance?date=YYYY-MM-DD`: handler مؤثر، `php/app/api/daily-performance-gps-separate.php` است که در index پیش از routes قدیمی ثبت می‌شود؛ sessionها، زمان GPS نامعتبر و شاخص‌های همان سرور نمایش داده می‌شوند.
- GET `/my/shift-schedule`: برنامه ماه جاری (نه ۱۴ روز آینده)، با انتساب/استراحت/تعطیلی و موظفی هر روز.
- GET `/my/attendance-history`: ۶۰ ثبت اخیر همان حساب با زمان‌های شمسی و خطوط ورود و خروج.

سیاست GPS، geofence، ساعت مجاز ورود و بسته‌شدن خودکار از همان سرور می‌آیند. ثبت ورود و خروج عادی در API فعلی عکس دریافت نمی‌کند؛ مرحلهٔ سلفی یا دوربین به‌طور موازی ساخته نشده است. نظارت/احراز حضور تصویری قابلیت جداگانه است.

## ایمنی رفتاری

یک عملیات هم‌زمان؛ بررسی نشست و generation صفحه، تازه‌خواندن حضور باز پیش و پس از GPS، رد وضعیت تغییرکرده، خطای صریح GPS/شبکه/عدم مجوز، تشخیص ack واقعی و auto_closed. درخواست آفلاین، موفقیت ثبت‌شده در سرور نامیده نمی‌شود. بعد از موفقیت، اطلاعات از سرور تازه می‌شوند. سابقه و دادهٔ محاسباتی مالی در cache عمومی SW ذخیره نمی‌شوند.

مرورگر امکان اسکن BSSID شبکه و GSM بومی Android را ندارد؛ اگر GPS برای خطوط فرد مجاز نباشد پیام صریح نمایش داده می‌شود و هیچ روش مجاز دیگری جعل نمی‌شود. نقشه آفلاین طبق درخواست مالک خارج از محدوده وب است.

## اعتبارسنجی

`node php/tests/web_attendance_test.cjs`: قرارداد GPS و مختصات صفر، double click، پاسخ صفحه قدیمی، تغییر جلسه هنگام GPS، قطع اینترنت، auto-close، نبود شیفت و عنوان برنامه ماهانه. آزمون در CI افزوده شد.

آزمون‌های web_features، Android/web navigation، screens و login policy نیز اجرا می‌شوند. build رسمی پنل اجرا و bundle syntax کنترل می‌شود؛ bundle بدون تغییر منبع پنل وارد commit نمی‌شود. اجرای GPS/دوربین روی دستگاه واقعی و نوشتن حضور واقعی برای آزمون روی تولید انجام نشده است؛ آزمون VM جای تأیید دستگاه واقعی نیست.
