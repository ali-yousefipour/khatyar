# اپلیکیشن Android خطیار

## مرجع مستندات

مستند مرجع یکپارچه کل پروژه در ریشه مخزن قرار دارد:

`../PROJECT_DOCUMENTATION.md`

فایل‌های Build Fix، Report و READMEهای قدیمی موجود در `mobile/` سابقه توسعه هستند. برای وضعیت فعلی امکانات، معماری و کارهای باقی‌مانده، ابتدا سند مرجع پروژه را بررسی کنید.

## راه‌اندازی توسعه

```bash
cd mobile
npm install
npx expo start
```

فونت‌ها و تنظیمات محیطی مطابق فایل‌های `.env.example` و راهنمای موجود در پروژه تنظیم شوند.

## ساخت APK / Myket

اسکریپت اصلی ساخت Myket:

```powershell
cd mobile
powershell -ExecutionPolicy Bypass -File .\build-myket-release.ps1
```

پروفایل‌های EAS در `eas.json` قرار دارند. قبل از Build باید نسخه‌های Node/Java، وابستگی‌ها، Expo، Gradle، NDK و Mirrorهای Myket مطابق سند مرجع بررسی شوند.

## اجزای مهم

- `App.js` — راه‌اندازی و ناوبری اصلی
- `src/auth.js` — احراز هویت و نشست
- `src/api.js` — ارتباط API و Refresh Token
- `src/device.js` — شناسه دستگاه و سیگنال‌های امنیتی
- `src/location.js` — موقعیت و ردیابی
- `src/offline.js` — عملیات آفلاین مجاز
- `src/crashReporter.js` — گزارش Crash
- `src/screens/` — صفحات و ماژول‌های برنامه
- `src/components/LineLocationCapture.js` — ثبت موقعیت و تصویر خطوط

## قابلیت ثبت موقعیت و تصویر خطوط

کاربر دارای Permission، خط را انتخاب می‌کند، موقعیت GPS و accuracy را دریافت می‌کند، موقعیت را روی نقشه می‌بیند و دو تصویر عملیاتی را ثبت می‌کند. داده‌ها از طریق API مربوط به Backend ذخیره و در بخش خطوط بروزرسانی می‌شوند.

جزئیات مشترک این قابلیت در:

`../docs/LINE_LOCATION_CAPTURE.md`

و سند مرجع کل پروژه ثبت شده است.

## اصل توسعه

هر قابلیت جدیدی که در Android اضافه می‌شود باید در صورت نیاز در Web App و Site/Admin نیز بررسی و یکسان‌سازی شود. تغییرات دیتابیس باید با MySQL/MariaDB سازگار، idempotent و قابل اجرای مجدد باشند.
