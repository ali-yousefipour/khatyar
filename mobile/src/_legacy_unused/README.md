# آرشیو کد مرده (بلااستفاده)

فایل‌های این پوشه پیاده‌سازی‌های قدیمی «ویزارد ثبت ایستگاه» هستند که در نسخهٔ فعلی برنامه
به هیچ صفحه/route ای وصل نیستند (هیچ import یا navigate ای به آن‌ها ارجاع نمی‌دهد).
نسخهٔ فعال و صحیح، `src/screens/StationCaptureV5Screen.js` است که از طریق
`StationCaptureScreen.js` و `StationCaptureV3Screen.js` (هر دو صرفاً re-export هستند) صدا زده می‌شود.

این فایل‌ها فقط برای مرجع تاریخی نگه داشته شده‌اند؛ در صورت اطمینان کامل می‌توانید
این پوشه را کلاً حذف کنید.

- StationCaptureScreenV2.js
- StationCaptureV4Screen.js
