# راهنمای ساخت APK با EAS (روش ابری — پیشنهادی)

این روش دانلودها را روی سرور Expo (خارج از ایران) انجام می‌دهد و شما فقط فایل APK نهایی را می‌گیرید.
برای وضعیت اینترنت ایران بسیار مطمئن‌تر از بیلد محلی است.

## پیش‌نیاز: اینترنت WSL باید کار کند
اول مطمئن شوید WSL به اینترنت وصل است:
```bash
ping -c 2 google.com
```
اگر جواب نداد، اول مشکل DNS/شبکهٔ WSL را حل کنید (راهنمای جداگانه).

---

## گام ۱: نصب ابزار EAS و ورود
```bash
cd ~/taxi/mobile
npm install -g eas-cli
eas login        # نیاز به حساب رایگان در https://expo.dev
```
(اگر حساب ندارید، در سایت expo.dev ثبت‌نام کنید — رایگان است.)

## گام ۲: مقداردهی پروژه (یک‌بار)
```bash
eas init
```
این کار یک `projectId` می‌سازد و به‌صورت خودکار در پیکربندی ثبت می‌شود.
این `projectId` برای کارکرد **نوتیفیکیشن Push** لازم است.

## گام ۳: ساخت APK
```bash
eas build -p android --profile preview
```
- در پایان یک **لینک دانلود APK** نمایش داده می‌شود.
- لینک را در مرورگر باز کنید، APK را دانلود و روی گوشی نصب کنید.
- بیلد روی سرور Expo انجام می‌شود (چند دقیقه طول می‌کشد).

## گام ۴ (اختیاری): نسخهٔ Play Store (AAB)
اگر بعداً خواستید در گوگل‌پلی منتشر کنید:
```bash
eas build -p android --profile production
```
خروجی این پروفایل فایل **AAB** است (مخصوص فروشگاه، نه نصب مستقیم).

---

## نکات مهم
- **Push:** برای کارکرد نوتیفیکیشن هنگام بسته‌بودن اپ، حتماً `eas init` را اجرا کنید تا `projectId` ساخته شود.
- **اسکن دوربین (OCR):** در APK واقعی کار می‌کند (در Expo Go نه).
- **موقعیت پس‌زمینه:** در APK واقعی کار می‌کند؛ هنگام اولین اجرا اجازهٔ موقعیت «همیشه» و اجازهٔ اعلان را بدهید.
- **فونت فارسی:** فایل‌های `assets/fonts/Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf` باید موجود باشند. اگر نبودند از https://github.com/rastikerdar/vazirmatn/releases دانلود کنید.
- **به‌روزرسانی نسخه:** برای بیلد بعدی، `ANDROID_VERSION_CODE` در `.env` را یک واحد زیاد کنید.

## اگر eas.dev از ایران مشکل داشت
- روی ویندوز VPN روشن کنید.
- در فایل `C:\Users\Administrator\.wslconfig` این را بگذارید تا WSL از شبکهٔ ویندوز (و VPN) استفاده کند:
  ```
  [wsl2]
  networkingMode=mirrored
  dns=true
  memory=6GB
  processors=4
  ```
- سپس در PowerShell: `wsl --shutdown` و دوباره اوبونتو را باز کنید.
