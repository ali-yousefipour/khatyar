# سامانه کنترل خطوط تاکسیرانی مشهد

این مخزن، **پایه و فاز نخست** سامانه است: شامل مدل دیتابیس، هستهٔ امن ورود و
بک‌اند، اسکریپت ساخت حساب‌های کاربری، اسکریپت ورود دادهٔ اکسل، و طرح اولیهٔ
رابط کاربری وب و موبایل. کل پروژه (با تمام جزئیاتی که توضیح دادید) یک کار
چندماهه است؛ این بسته زیربنای درست را می‌گذارد تا بقیه ماژول‌ها روی آن ساخته شود.

> ⚠️ بخش‌هایی مثل تشخیص VPN، فعال‌بودن Developer Options و روشن‌بودن GPS
> ذاتاً **سمت دستگاه** هستند: اپ موبایل آن‌ها را می‌سنجد و به سرور می‌فرستد،
> و سرور بر اساس همین سیگنال‌ها (پیاده‌سازی‌شده در `auth/login`) ورود را مسدود می‌کند.

---

## معماری و کتابخانه‌های آماده

| لایه | فناوری (کتابخانه‌های آماده) |
|------|------|
| دیتابیس | **PostgreSQL** (مناسب برای ۱M+ رکورد فیش) |
| بک‌اند | **Node.js + Express**، `pg`، `bcryptjs`، `jsonwebtoken`، `zod`، `helmet` |
| وب (پنل مدیریت) | پیشنهاد: **React + Vite**، نقشه با **Leaflet/MapLibre**، چارت سازمانی با **react-flow** (درگ‌اند‌دراپ)، نمودار با **Recharts** |
| موبایل اندروید | پیشنهاد: **React Native (Expo)** یا **Flutter**؛ موقعیت‌یابی پس‌زمینه، حالت آفلاین با **SQLite/WatermelonDB**، فونت **وزیرمتن** |
| اسکن پلاک/کارت ملی | **ML Kit (Text Recognition)** سمت دستگاه + سرویس OCR فارسی برای تشخیص شماره پلاک و کد ملی |

## راه‌اندازی (نسخهٔ ۰.۲ — با نصاب خودکار)

جزئیات کامل در **`INSTALL.md`**. خلاصه:
- **داکر:** `docker compose up -d` سپس **http://localhost:4000/install**
- **دستی:** `cd backend && npm install && npm start` سپس **/install**
- **اپ موبایل:** در `mobile/` فایل `.env` را از `.env.example` بسازید (آدرس سرور)، یا هنگام اولین اجرا در صفحهٔ «اتصال به سرور» وارد کنید.

## وضعیت — این بسته شامل کد کامل هر دو برنامه است

### ✅ بک‌اند (Node + Express + PostgreSQL)
- ورود با اتصال تک‌دستگاهی، تمدید توکن، مرا به خاطر بسپار، مسدودسازی VPN/Developer Options/GPS
- کنترل دسترسی سلسله‌مراتبی، جستجو، حضور (قاعدهٔ ۵ دقیقه)، بدهی + لینک درگاه، تذکر، چک‌لیست
- آمار داشبورد، چارت سازمانی، تخصیص خط، CRUD تنظیمات، گردش گزارش‌ها، لاگ‌ها، نقشهٔ زنده و رهگیری روزانه، آپلود اکسل
- ساخت ۶۸ حساب کاربری + اسکریپت ورود دادهٔ اکسل

### ✅ پنل وب
برنامهٔ تک‌فایلی و **آماده اجرا در مرورگر** (React + Leaflet + Chart.js). شامل: ورود، داشبورد،
نقشهٔ زنده + رهگیری روزانه، **مدیریت کاربران (افزودن/ویرایش/فعال‌سازی/حذف دستگاه)**،
**منطقه‌بندی نیروها (درگ‌اند‌دراپ)**، **تخصیص خطوط مجاز به هر نیرو**، چارت سازمانی،
رانندگان، آبونمان، تنظیم تذکر/چک‌لیست، فرم‌ساز، گردش گزارش‌ها، ورود اکسل، لاگ‌ها و تنظیمات سامانه.
برای داده واقعی، `USE_MOCK = false`.

### ✅ اپ موبایل اندروید (`mobile/` — Expo / React Native)
کد کامل همهٔ صفحات و منطق برنامه. روی سیستم شما با `npm install` و `expo start` اجرا و با `eas build` به APK
تبدیل می‌شود. راهنما در `mobile/README.md`.

## مواردی که باید روی سیستم/دستگاه شما تکمیل شود ⚙️
این‌ها به سخت‌افزار، کلید سرویس، یا build بومی نیاز دارند و در محیط چت قابل انجام نیستند؛ نقطهٔ اتصالشان در کد مشخص است:
1. **اسکن پلاک/کارت ملی با هوش مصنوعی** (دوربین + ML Kit) — `mobile/src/screens/SearchScreen.js`
2. **تشخیص Developer Options** (react-native-device-info) — `mobile/src/device.js`
3. **ردیابی موقعیت در پس‌زمینه** (TaskManager) — `mobile/src/location.js`
4. **ساخت APK** با `eas build` و **استقرار سرور/دیتابیس**
5. کاشی نقشهٔ واقعی/کلید سرویس نقشه برای محیط عملیاتی

> رمز یکسان ۱۲۳۴۵۶ فقط برای راه‌اندازی اولیه است؛ الزام تغییر رمز در نخستین ورود فعال نگه داشته شود.

## نسخهٔ ۰.۴ — گزارش‌گیری پیشرفته + بارگذاری/تست داده
- پنل: منوی «گزارش‌گیری پیشرفته» با فیلتر نوع/تاریخ/شخص و **خروجی Excel واقعی (xlsx)** و **چاپ/PDF**.
- importer کامل شد: خطوط، رانندگان، **پروانهٔ بهره‌برداری + خودروها**، پروانهٔ تاکسیرانی، و فیش‌ها.
- بارگذاری یک‌مرحله‌ای از پوشهٔ اکسل:
  ```
  DATABASE_URL=postgres://... ./backend/scripts/load_all.sh /path/to/excel-folder
  ```
- دادهٔ آزمایشی برای تست کامل بدون فایل‌های بزرگ:
  ```
  cd backend && npm run seed:demo
  ```
  (۳ خط، ۳ راننده/خودرو با وضعیت پروانهٔ متفاوت برای تست هشدار، ۹ فیش، چک‌لیست و فرم نمونه)

## نسخهٔ ۰.۵ — همهٔ ماژول‌ها واقعی
- پنل وب اکنون **به‌صورت خودکار** تشخیص می‌دهد پشت سرور است یا نه (از طریق `/api/health`):
  پشت سرور → همهٔ بخش‌ها با **داده و عملیات واقعی** کار می‌کنند (کاربران، مناطق، خطوط، بدهی،
  تذکر/چک‌لیست، گردش گزارش‌ها، گزارش‌گیری Excel/PDF، تنظیمات، لاگ‌ها، ورود اکسل، نقشه).
  باز کردن مستقیم فایل → حالت دموی نمونه.
- endpointهای جدید بک‌اند: `/admin/bills`، `/admin/report`.
- تست دود endpointها: `BASE_URL=... ADMIN_USER=... ADMIN_PASS=... npm run test:smoke`

## نسخهٔ ۰.۶ — حضور مسئولین در خط + موارد تکمیلی
- **قابلیت جدید «ثبت حضور مسئولین در خط»**: در اپ موبایل، اپراتور/ناظر خط می‌تواند حضور مسئولین
  (معاونت، رییس اداره، سربازرس ارشد، نیروهای اداری، بازرسین) را با خط و توضیحات و موقعیت ثبت کند؛
  در همان صفحه نمودار حضور مسئولین (۳۰ روز) نمایش داده می‌شود. در پنل وب، منوی «حضور مسئولین در خط»
  برای رییس اداره/مدیرکل شامل جدول قابل‌فیلتر، خروجی Excel و نمودار حضور هر مسئول است.
- نمودار دوم داشبورد: حضور به‌تفکیک خط (۳۰ روز).
- صفحهٔ گردش گزارش: نمایش گردش واقعی (ارجاع/نظر/پاسخ) از سرور.
- **مستندات API**: Swagger UI در آدرس `/docs.html` و فایل `/openapi.yaml` (۳۰ مسیر).

## پیاده‌سازی روی هاست app.yousefipour.ir
فایل تنظیمات آمادهٔ هاست: `backend/.env.production` (روی هاست به `.env` تغییر نام دهید).
نصب غیرتعاملی: `node scripts/install_prod.js` (جداول + حساب مدیرکل + ۶۸ حساب پرسنل).
راهنمای کامل گام‌به‌گام cPanel/دامنه/HTTPS: `deploy/HOST_SETUP_app.yousefipour.ir.md`.
> این سامانه Node.js + PostgreSQL است؛ اگر هاست فقط MySQL/PHP باشد، راهنما حالت‌های جایگزین (VPS یا انتقال به MySQL) را توضیح داده است.

قابل افزودن به صفحهٔ اصلی موبایل است). راهنما: `php/README.md`.
