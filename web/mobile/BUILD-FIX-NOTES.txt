Khatyar Android build fix - correct project version

Changes in this package:
1. The risky custom ABI-split plugin is no longer active. assembleRelease now creates the standard universal release APK.
2. The optional Myket Gradle repository plugin is no longer active. Gradle uses the official repositories generated by Expo.
3. react-native-worklets is locked to 0.10.0 and Reanimated to 4.5.0.
4. package-lock.json is included and npm ci is used, so every build installs the same dependency tree.
5. Babel uses only babel-preset-expo; Expo SDK 57 configures Reanimated/Worklets automatically.
6. Local config plugins import expo/config-plugins, ensuring the same config-plugin version as Expo.
7. expo install --fix was removed from release builds because it mutates dependencies during the build.
8. Gradle global init scripts are detected and bypassed using an isolated GRADLE_USER_HOME.
9. The redundant gradlew clean stage was removed after expo prebuild --clean.
10. Full Gradle error context and log paths are retained in reports.
11. JDK 17 is validated before building.

Run from PowerShell:
  Set-Location F:\taxi-system\mobile
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build-myket-release.ps1 -Fresh

Expected output:
  F:\taxi-system\mobile\android\app\build\outputs\apk\release\app-release.apk
