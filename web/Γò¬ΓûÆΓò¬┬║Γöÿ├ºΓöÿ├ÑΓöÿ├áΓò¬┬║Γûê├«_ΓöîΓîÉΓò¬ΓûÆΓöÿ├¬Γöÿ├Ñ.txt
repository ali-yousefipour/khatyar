========================================
راهنمای تنظیم Cron (زمان‌بندی خودکار) — مبتنی بر PHP
شرکت مبین شات مشهد
========================================

چون سرور شما فقط اجرای فایل PHP را در Cron می‌پذیرد (نه curl/wget)،
یک فایل جامع به نام cron.php ساخته شد که همهٔ کارهای خودکار را انجام می‌دهد.
این فایل کنار index.php در پوشهٔ public قرار دارد.

== تنظیم در cPanel → Cron Jobs ==

۱) خروج خودکار رانندگانِ جامانده در خط (هر ۱۵ دقیقه):
   مسیر کامل php را در cPanel وارد کنید. نمونه:
   /usr/local/bin/php /home/h301194/public_html/cron.php auto-exit
   زمان‌بندی: */15 * * * *

۲) کارهای روزانه (پیامک/پوش انقضا + تبریک تولد + پاکسازی تصاویر):
   /usr/local/bin/php /home/h301194/public_html/cron.php daily
   زمان‌بندی: 0 8 * * *   (هر روز ساعت ۸ صبح)

== کارهای قابل اجرا (آرگومان‌ها) ==
   auto-exit    → فقط خروج خودکار رانندگان
   sms-expiry   → فقط پیامک هشدار انقضا
   push-expiry  → فقط پوش هشدار انقضا
   birthday     → فقط تبریک تولد
   cleanup      → فقط پاکسازی تصاویر قدیمی
   daily        → همهٔ کارهای روزانه (به‌جز auto-exit)
   all          → همهٔ کارها با هم (پیش‌فرض)

== نکات ==
- مسیر دقیق فایل و مسیر php را از File Manager / بخش Cron هاست بردارید.
- اگر مسیر php را نمی‌دانید، معمولاً یکی از این‌هاست:
    /usr/local/bin/php   یا   /usr/bin/php   یا   /opt/cpanel/ea-php82/root/usr/bin/php
- خروجی هر اجرا به‌صورت JSON چاپ می‌شود؛ می‌توانید آن را در لاگ Cron ببینید.
- پاکسازی تصاویر بر اساس همان تنظیمات پنل («حذف خودکار تصاویر و پیوست‌ها») عمل می‌کند.

== ساعت خروج خودکار ==
ساعت پیش‌فرض خروج خودکار ۳ ساعت است. برای تغییر، در جدول app_settings
کلید auto_exit_hours را تنظیم کنید (یا از طریق پنل در صورت وجود گزینه).
