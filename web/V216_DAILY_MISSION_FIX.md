# V216 — اصلاح کامل «مأموریت روزانه من»

- حذف وابستگی به ستون ناموجود `attendances.exit_at` و استفاده از رکوردهای روز جاری.
- اصلاح کوئری بدهکاران آبونمان در محاسبه مأموریت.
- اصلاح ترتیب تشخیص سمت تا سربازرس پیش از بازرس بررسی شود.
- توسعه نگاشت سمت‌ها برای عناوین «رئیس خط»، «ناظر»، «بازرس ارشد»، «رئیس اداره بازرسی»، «گشت خودرویی» و عناوین انگلیسی متناظر.
- حذف پنهان‌سازی خطای واقعی API مأموریت و بازگرداندن خطای استاندارد با کد `MISSION_CALCULATION_FAILED`.
- افزودن fallback واقعی در اپ؛ پاسخ خالی یا هشدار نیز باعث فراخوانی API جایگزین می‌شود.
- نمایش warning واقعی سرور در صفحه به‌جای پیام گمراه‌کنندهٔ ثابت.
