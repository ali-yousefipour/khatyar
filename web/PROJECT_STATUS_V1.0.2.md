# گزارش وضعیت انجام‌شده‌ها و باقی‌مانده‌ها تا نسخه 1.0.2

- حضور و غیاب و تشخیص خط
- شیفت خودکار و محاسبه موظفی/اضافه‌کار/مازاد
- تحویل شیفت با QR
- شب‌کاری، جمعه‌کاری و تعطیل‌کاری
- گزارش‌ها، ویرایش، حذف و بایگانی
- اعلان‌ها، پیامک، Push و ربات بله
- رانندگان موقت و جستجوی خودرو/بهره‌بردار/کمکی
- فیش حقوقی PDF
- صداهای اختصاصی اپ
- رفع خطاهای تاریخ تولد و جستجوی کد ملی
- نسخه‌بندی سایت و اپ
- صف پایدار پیام‌ها
- Rule Engine پایه برای قوانین کارکرد
- upgrade.php تجمیعی
- صف آفلاین موبایل
- لاگ سلامت فنی

- اتصال به منبع رسمی تعطیلات در صورت وجود API معتبر
