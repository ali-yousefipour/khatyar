# توضیح مجوزها برای بررسی مایکت

- **دوربین:** ثبت تصاویر عملیاتی، اسکن مدارک و تشخیص پلاک.
- **موقعیت دقیق:** کنترل محدوده مجاز و ثبت تردد کاربران سازمانی.
- **موقعیت پس‌زمینه:** فقط برای نقش‌ها و عملیات فعال نیازمند پایش خدمت؛ استفاده عادی برنامه را مسدود نمی‌کند.
- **اعلان:** نمایش پیام‌های سازمانی و نتیجه عملیات.
- **اینترنت و وضعیت شبکه:** ارتباط HTTPS با سرور و همگام‌سازی صف آفلاین.
- **Foreground service:** حفظ فرایند موقعیت در عملیات فعال و قابل مشاهده برای کاربر.
- **راه‌اندازی پس از روشن‌شدن دستگاه:** بازیابی اعلان‌ها یا وظایف سازمانی فعال.
