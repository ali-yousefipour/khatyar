# v182 — فاز ۴ پایش سلامت دستگاه‌ها

## نسخه‌ها
- اپ اندروید: 1.3.41 (versionCode 10341)
- سایت/API: 127

## قابلیت‌های اپ
- ثبت دوره‌ای سلامت هر ۵ دقیقه و هنگام ورود برنامه به پس‌زمینه/پیش‌زمینه
- باتری، حالت ذخیره انرژی، شبکه، دسترسی اینترنت، IP محلی
- فضای آزاد و کل حافظه ذخیره‌سازی
- حافظه کل دستگاه (در صورت پشتیبانی)
- مدل، سازنده، نسخه اندروید، نسخه و بیلد اپ
- سنجش زمان پاسخ API و وضعیت دسترسی سرور
- صف آفلاین با حداکثر ۳۰ گزارش و ارسال مجدد خودکار
- جلوگیری از ارسال بیش از حد و اجرای تکراری Monitor

## قابلیت‌های سرور و پنل
- POST /api/activity/device-health
- GET /api/admin/device-health
- GET /api/admin/device-health/{user_id}/history
- نگهداری تاریخچه و آخرین وضعیت هر دستگاه
- نمایش سلامت دستگاه‌ها در داشبورد سلامت سامانه
- هشدار برای گزارش قدیمی، قطع شبکه/API، باتری کمتر از ۱۵٪، فضای کمتر از ۵۱۲MB و پاسخ API کند
