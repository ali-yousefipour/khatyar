# نسخهٔ PHP + MySQL — سامانه کنترل خطوط تاکسیرانی مشهد

این نسخه برای هاست‌های اشتراکی (cPanel) با **PHP و MySQL** ساخته شده و دقیقاً همان APIهای نسخهٔ Node را ارائه می‌دهد؛
پنل وب و اپ موبایل و **وب‌اپ مرورگری** همگی به آن وصل می‌شوند.

## ساختار
```
php/
  config.php            تنظیمات (از .env می‌خواند)
  lib/                  Db, Jwt, Http, Push, Xlsx, routes
  db/mysql_schema.sql   اسکیمای MySQL
  seed/personnel.json   ۶۸ پرسنل
  public/   ← این پوشه را docroot سابدامین قرار دهید
    index.php           فرانت‌کنترلر و روتر API
    install.php         نصاب وب
    panel.html          پنل مدیریت
    app.html            وب‌اپ موبایل (PWA)
    manifest.json, sw.js, icon-*.png, docs.html, openapi.yaml, favicon.svg
    .htaccess
```

## نصب روی cPanel (app.yousefipour.ir)
1. **دیتابیس:** در cPanel → MySQL Databases، دیتابیس `h301194_app` و کاربر `h301194_app` را بسازید و کاربر را با همهٔ دسترسی‌ها به دیتابیس اضافه کنید.
2. **ساب‌دامین:** `app.yousefipour.ir` را بسازید و **Document Root** آن را به پوشهٔ `php/public` اشاره دهید (یا محتوای `public` را در پوشهٔ ساب‌دامین بگذارید و `lib`,`config.php`,`db`,`seed` را یک سطح بالاتر از docroot قرار دهید).
3. **آپلود:** کل پوشهٔ `php/` را آپلود کنید.
4. **نصب:** به `https://app.yousefipour.ir/install.php` بروید و فرم را کامل کنید (اطلاعات دیتابیس از پیش پر است؛ فقط حساب مدیرکل را وارد کنید). این کار جداول، حساب مدیرکل و ۶۸ پرسنل (رمز ۱۲۳۴۵۶) را می‌سازد و فایل `.env` را می‌نویسد.
5. **HTTPS:** در cPanel → SSL/TLS Status، AutoSSL را برای دامنه فعال کنید.
6. بررسی سلامت: `https://app.yousefipour.ir/health`

## آدرس‌ها
- پنل مدیریت: `https://app.yousefipour.ir/`
- **وب‌اپ موبایل (بدون نصب APK): `https://app.yousefipour.ir/app`** — قابل نصب روی صفحهٔ اصلی موبایل (Add to Home Screen).
- مستندات API: `https://app.yousefipour.ir/docs.html`

## ورود اطلاعات اکسل
از پنل → «ورود اطلاعات (اکسل)» فایل‌های سامانه جامع را آپلود کنید (خوانندهٔ xlsx در `lib/Xlsx.php` پیاده‌سازی شده).

## اپ موبایل نیتیو (اختیاری)
اگر خواستید APK هم بسازید، در `mobile/.env` مقدار `API_BASE=https://app.yousefipour.ir/api` را بگذارید و `eas build` کنید.
> نکته: وب‌اپ مرورگری و اپ نیتیو هر دو «یک دستگاه» محسوب می‌شوند؛ به‌دلیل قانون اتصال تک‌دستگاهی، استفادهٔ هم‌زمان از هر دو ممکن است نیاز به «حذف دستگاه» توسط مدیرکل داشته باشد.

## امنیت
رمز دیتابیس را پس از راه‌اندازی تغییر دهید. `.env` و پوشه‌های `lib/config` خارج از docroot یا غیرقابل‌دسترسی از وب نگه داشته شوند.

## ارتقای قابلیت‌ها (نصب موجود)
اگر قبلاً نصب کرده‌اید، برای فعال‌شدن قابلیت‌های جدید (احراز هویت دو‌دستگاهی، ایمیل/عکس کاربر، پاسخ‌های دلخواه چک‌لیست، پیوست پیام) یک‌بار فایل `php/db/upgrade.sql` را در phpMyAdmin روی دیتابیس اجرا کنید.
> پس از این تغییر، همهٔ کاربران باید یک‌بار دوباره وارد شوند (نشست‌ها بازسازی می‌شوند).
