✅ علت اصلی و قطعی صفحهٔ سفید پیدا و رفع شد:

از روی لاگ گوشی، خطای دقیق مشخص شد:
   ReferenceError: Property 'ThemeProvider' doesn't exist  (in App)

یعنی کامپوننت ThemeProvider در فایل App.js استفاده شده بود اما
خط import آن جا افتاده بود. در حالت توسعه (Metro) این خطا گاهی
نادیده گرفته می‌شد، اما در نسخهٔ نصبی (موتور Hermes) باعث
صفحهٔ سفید کامل می‌شد.

اکنون این خط import اضافه شد:
   import { ThemeProvider } from './src/themeContext';

همچنین از لاگ مشخص شد که APK یونیورسال درست کار می‌کند
(فایل libreactnativejni.so روی arm64-v8a پیدا شد)، پس
غیرفعال‌کردن ABI splits در نسخهٔ قبل درست بوده است.

== نحوهٔ ساخت نسخهٔ جدید ==
۱) در پوشهٔ mobile:
   npx expo prebuild --clean
۲) بیلد:
   eas build -p android --profile production
   یا محلی:
   cd android && ./gradlew assembleRelease
۳) فایل خروجی (APK یونیورسال) را نصب کنید:
   android/app/build/outputs/apk/release/app-release.apk

این نسخه (۰.۴.۳) دیگر صفحهٔ سفید نخواهد داشت.
