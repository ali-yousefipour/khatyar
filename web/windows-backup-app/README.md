# نرم‌افزار پشتیبان‌گیری و مرور آفلاین — سامانهٔ تاکسیرانی

این نرم‌افزار ویندوزی به شما اجازه می‌دهد **کل اطلاعات سامانه** (تنظیمات، پرسنل، خطوط، رانندگان، گزارش‌ها، چک‌لیست‌ها، ترددها، تذکرها، تصاویر و …) را از سرور دانلود کرده، در یک پایگاه‌دادهٔ محلی (SQLite) ذخیره کنید و به‌صورت **کاملاً آفلاین** روی ویندوز مرور و استفاده نمایید.

## نصب و اجرا

### روش ۱ — اجرای مستقیم با پایتون
1. پایتون ۳.۸ یا بالاتر را از python.org نصب کنید (هنگام نصب، گزینهٔ Add to PATH را بزنید).
2. کتابخانهٔ موردنیاز را نصب کنید:
   ```
   pip install requests
   ```
3. برنامه را اجرا کنید:
   ```
   python taxi_backup.py
   ```

### روش ۲ — ساخت فایل اجرایی (EXE) برای ویندوز
بدون نیاز به نصب پایتون روی سیستم مقصد:
```
pip install pyinstaller requests
pyinstaller --onefile --noconsole --name "TaxiBackup" taxi_backup.py
```
فایل خروجی در پوشهٔ `dist\TaxiBackup.exe` ساخته می‌شود و روی هر ویندوزی بدون نیاز به پایتون اجرا می‌شود.

## نحوهٔ کار

### مرحلهٔ ۱ — دریافت پشتیبان (تب «دریافت پشتیبان»)
1. **آدرس سرور**: مثلاً `https://app.yousefipour.ir`
2. **توکن ادمین**: توکن دسترسی مدیر. آن را از پنل وب (از طریق ابزار توسعه‌دهندهٔ مرورگر → Application/Storage، یا از مقدار ذخیره‌شدهٔ ورود) کپی کنید. این توکن باید متعلق به یک حساب **مدیر (ادمین)** باشد.
3. گزینه‌ها:
   - **حالت سبک**: تصاویرِ ذخیره‌شده به‌صورت base64 داخل دیتابیس را نادیده می‌گیرد (دانلود سریع‌تر و سبک‌تر).
   - **دانلود فایل‌های تصویر**: آلبوم تصاویر فیزیکی (سلفی‌ها، عکس گزارش‌ها و …) را جداگانه دانلود می‌کند.
4. روی **«⬇ دریافت و ایمپورت پشتیبان از سرور»** بزنید.

به‌صورت ماهیانه می‌توانید این کار را تکرار کنید؛ هر بار یک نسخهٔ کامل و به‌روز ساخته می‌شود.

### مرحلهٔ ۲ — مرور آفلاین (تب «مرور داده‌ها»)
- فهرست تمام جدول‌های سامانه را با تعداد ردیف‌ها می‌بینید.
- روی هر جدول کلیک کنید تا محتوای آن نمایش داده شود.
- با کادر **جستجو** می‌توانید در میان داده‌ها جستجو کنید.

### مرحلهٔ ۳ — تصاویر (تب «تصاویر»)
- فهرست همهٔ فایل‌های تصویر دانلودشده را می‌بینید و می‌توانید پوشهٔ آن‌ها را باز کنید.

## محل ذخیره‌سازی
همهٔ داده‌ها در پوشهٔ زیر ذخیره می‌شوند:
```
C:\Users\<نام‌کاربری>\TaxiBackup\
```
شامل:
- `taxi_offline.db` — پایگاه‌دادهٔ آفلاین (SQLite)
- `media\` — تصاویر دانلودشده
- `backup_*.json` — فایل‌های پشتیبان خام دریافتی
- `config.json` — تنظیمات اتصال

## دسترسی برنامه‌نویسی به دیتابیس آفلاین
پایگاه‌دادهٔ `taxi_offline.db` یک فایل استاندارد SQLite است. می‌توانید با هر ابزاری (DB Browser for SQLite، یا کد پایتون/سی‌شارپ) به همهٔ جدول‌ها و داده‌های سامانه دسترسی داشته باشید:

```python
import sqlite3
con = sqlite3.connect(r"C:\Users\YOU\TaxiBackup\taxi_offline.db")
con.row_factory = sqlite3.Row
for r in con.execute("SELECT first_name,last_name,personnel_code FROM users"):
    print(dict(r))
```

ساختار جدول‌ها دقیقاً مطابق دیتابیس سرور است (همان نام جدول‌ها و ستون‌ها).

## نکات
- توکن ادمین را محرمانه نگه دارید؛ این توکن دسترسی کامل به داده‌های سامانه می‌دهد.
- اگر دانلود تصاویر کند است، می‌توانید تیک آن را بردارید و فقط دیتابیس را بگیرید.
- برای بکاپ ماهانه، توصیه می‌شود فایل‌های `backup_*.json` را در جای امنی نگه دارید.
