# وضعیت پروژه — نسخه 1.0.14

نسخه 1.0.14 روی توسعه ربات بله متمرکز است.

## وضعیت
- امکانات اصلی ربات تعاملی بله پیاده‌سازی شد.
- ربات از منو، پاسخ سفارشی و فرم‌های چندمرحله‌ای پشتیبانی می‌کند.
- فرم‌ها می‌توانند با دریافت کد ملی، اطلاعات راننده/کاربر را از دیتابیس پر کنند.
- پنل مدیریت نمونه عملیاتی برای منو، پاسخ‌ها، فرم‌ها و ثبت‌نام‌ها اضافه شد.
